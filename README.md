# Prática Avaliada 1 — Engenharia de Software I

**Aluno:** Rafael Oliveira Molina  
**Tema:** Manifesto Ágil, XP, Scrum, Kanban e Design Simples (YAGNI)

## Sobre a atividade

Esta entrega apresenta uma proposta de processo ágil para a startup fictícia AgileTech Solutions. O trabalho aplica os valores do Manifesto Ágil, combina práticas de XP com o framework Scrum, estrutura um quadro Kanban e refatora um código Python segundo o princípio YAGNI.

## Estrutura

- `analise-processo.md`: aplicação do Manifesto Ágil, programação em pares e dificuldades essenciais de Brooks.
- `processo-xp-scrum.md`: práticas de XP, integração com Scrum, quadro Kanban e cronograma da Sprint.
- `analise-yagni.md`: identificação das funcionalidades antecipadas e justificativa da refatoração.
- `src/usuario_simples.py`: implementação simplificada do cadastro, login e listagem de usuários.

## Executando o código

É necessário ter Python 3.10 ou superior. Na raiz do projeto, execute:

```bash
python src/usuario_simples.py
```

O exemplo cadastra dois usuários, realiza um login válido e lista os usuários cadastrados.

## Observação sobre o GitHub Projects

O quadro está especificado em `processo-xp-scrum.md`, com colunas, limites de trabalho em andamento, cards e critérios de aceite. Depois de publicar este projeto no GitHub, deve-se criar o Project seguindo essa especificação e substituir o campo indicado pelo endereço do quadro criado.
